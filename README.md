# PI2 - Sistema de triagem médica

Segundo projeto integrador - Site para Triagens médicas simplificado utilizando a linguagem de programação JavaScript, com o intuíto de descrever sintomas e agendamentos de consultas para instituições públicas (Estilo SUS).

## Resumo

todos já devem ter passado por um problema muito comum nesta simplória existência... precisar ir no hospital pois está com um problema de saúde grave para resolver e ter que ficar incontáveis horas esperando para ser atendido, sendo que em muitas das vezes os médicos irão apenas receitar alguns medicamentos e pedir uma enorme quantidade de exames para serem feitos para um melhor diagnóstico, pensando nisso, vem uma dúvida em mente: porque não diminuir esse tempo gasto no hospital? Não podemos diminuir o tempo da consulta e os exames, porém podemos ajustar a logistica por trás dos pacientes na fila de espera para que todos sejam atendidos e  não gastem muito tempo esperando.

O objetivo deste projeto consiste na criação de um sistema para triagem médica para organizar agendamentos de pacientes de acordo com as semanas levando em consideração alguns fatores específicos como: enfermidade do paciente (usando como um simples exemplos algumas doenças); grau de risco e prioridade de atendimento do mesmo.
